Quotex session helper

Build a session.json for the predictor bot — entirely on your phone.

The token is like a password. Do not share it, paste it in chats, or commit it to Git. Keep it only in your bot's secret environment.

Step 1 — get the token (bookmarklet)

  1. Open Quotex in Kiwi Browser and log in.
  2. Save this as a bookmark (long-press, Add bookmark, paste the address):
    Quotex token
  3. On the Quotex tab, open that bookmark. A box shows your token and user agent — copy it.

Step 2 — get the cookies

  1. In Kiwi Browser, install the Cookie-Editor extension.
  2. On the Quotex tab, open Cookie-Editor, Export, JSON.
  3. Paste the exported JSON below (it includes HttpOnly cookies like cf_clearance).

Step 3 — build session.json

—

Save the output as session.json, then run:
QUOTEX_SESSION_FILE=session.json DATA_SOURCE=quotex python bot.py
